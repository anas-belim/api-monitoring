# API Monitoring & Uptime Dashboard

A Spring Boot application for monitoring APIs and tracking their availability,
response time, uptime, and incidents.

## Tech Stack

- Java
- Spring Boot
- Maven
- PostgreSQL
- Spring Data JPA
- Spring Security
- Docker
- GitHub Actions

## Project Goals

- Monitor external APIs
- Measure response time
- Track API availability
- Calculate uptime
- Detect incidents
- Send alerts
- Provide monitoring dashboard
